# Modèles CI archivés

Ces YAML sont conservés hors de `.github/workflows` et ne déclenchent aucune action GitHub.

- `qa.yml` et `performance.yml` : anciennes propositions utilisant Docker pour les tests, à adapter à la stratégie native.
- `deployed-playwright.yml` : brouillon pour le frontend déployé, non validé sur GitHub.

Ils ne constituent pas le futur pipeline de construction des deux images. Voir [la préparation CI/CD](../ci-cd.md) avant réutilisation.
